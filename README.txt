AMMA KONGU WEBSITE — REFERENCE-MATCHED EDITION
================================================
This build follows the uploaded reference image: ivory background, royal maroon highlights, gold detailing, top contact strip, brand header, hero, benefit strip, six collection tiles, story/statistics, gallery pagination and enquiry form.

IMAGE QUALITY:
- Image files are included locally in /images.
- The image assets are cropped from the supplied 1536 x 1024 reference at their native on-screen dimensions.
- CSS does not apply blur or soft-focus filters.
- The category images are intentionally displayed at the same 227 x 140 px visual size as in the reference.
- For a production launch, replace these reference crops with original full-resolution product photographs. Cropping a screenshot cannot recover detail beyond the source screenshot.

SETUP:
1. Extract the ZIP and open index.html in Chrome/Edge.
2. Update shop phone/address/social links in index.html.
3. Update WHATSAPP_NUMBER in script.js to your actual business WhatsApp number.
4. Replace image files in /images with original high-resolution saree photos, keeping the same filenames and aspect ratios.
5. Google Fonts need an internet connection; fallback fonts will be used offline.

This is a static front-end website. It does not include a backend, admin panel, customer database, POS or inventory management.
